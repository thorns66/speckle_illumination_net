# 卷积结构先验的初始梯度检查

## 当前决策

暂不把“加入卷积先验”当作已经解决 N100 协方差重建伪纹理的方案，也不据此替换正式 no_mean。N100 上，VAR 引导的初始参数梯度在三个种子下均与独立帧、总体物理参考相反；N800 上存在值得继续验证的方向一致性，但还没有完成新网络的 200 步重建，更没有证明分辨率或三维深度改善。

本项复用已缓存梯度，CPU 实际分析用时约 3.94 秒，没有加载大型 Cs 矩阵、没有占用 A40、没有执行重建更新。结果文件：

`outputs/linear_float_oracle_50um/convolutional_tangent/initial_readout.json`

## 为什么做这项检查

[Deep Image Prior](https://arxiv.org/abs/1711.10925) 支持“卷积生成器自身可以提供图像先验”，但不能据此断言它能修复当前有限帧、非线性协方差重建。像素优化的失败也不是光学系统或所有网络求解器的上限。

本次用有限网络的链式法则检查初始更新。若残差对参数的 Jacobian 为 J：

- 参数梯度为 Jᵀ∇R L。
- 普通梯度下降诱导的残差更新为 −JJᵀ∇R L。
- 对 J 的列空间做正交投影不是同一个更新，不能把两者混称为 CNN 的“降噪”。
- Adam 第一更新还会按参数梯度大小重新缩放，因此单独计算其输出方向。
- 即使两组预处理后的更新彼此相似，也要检查训练更新是否确实是原始独立帧/总体目标的下降方向。

[NTK 原论文](https://arxiv.org/abs/1806.07572) 是相关理论背景；这里使用有限网络的精确初始链式法则，不套用无限宽、固定核或凸损失的收敛保证。

## 实验范围

- 固定已授权的 50 µm 横向诊断，不做任意三维重建，不使用目标图像生成网络特征。
- N100 与 N800 各使用本数据集的 RL3 anchor，匹配缓存梯度的非负截断和单位质量归一化。
- 重用精确有限源 Cs 的初始梯度：训练帧、独立帧、总体 oracle 参考。总体参考只用于诊断，不能部署时访问。
- 缓存 sensor probes 为 256/512 嵌套前缀；两种 loss 为原 per-probe 相对误差及 global-fixed 归一化误差。
- 网络种子固定 20260901/02/03，不择优挑种子。
- 两种输入为 RMS 归一化 VAR anchor、固定种子 20261040 的白噪声。每个数据集内不同种子共享同一输入。
- 复用已有 SharedFrameEncoder、ConvBlock2D，搭建当前三尺度 decoder 的二维对应结构；通道 16/32/64，reflect context 40，零初始化 1×1 readout。
- 这是独立诊断网络，不是正式三分支网络的完整 Jacobian；未修改 Set、gate、PSF、生产模型或均值反传。
- 梯度源和 anchor 的 SHA256 写入报告。缓存梯度的常数分量相对范数最大约 1.07e−8，按单位质量参数化的零方向移除。
- 共 48 个记录是 2 数据量 × 2 输入 × 3 种子 × 2 probe 前缀 × 2 loss 的相关视图，不能当作 48 次独立数据重复。

## 零初始化的重要限制

最后一层权重为零时，第一步只有 16 个 readout 权重可以改变形状；前面的卷积特征层参数梯度严格为零。输出常数偏置在初始单位质量归一化下也是零方向。

本次所有特征矩阵数值秩均为 16，条件数约 4.42–23.34。该初始低维限制不是网络完整训练后的表达能力。特别是，不得把初始方向门槛作为 200 步成功的必要条件，或用它否定所有 DIP/卷积先验。

## 512 probes、原 per-probe loss 的结果

下表余弦均为参数梯度夹角，正值代表方向相容，负值代表相反。

| 数据/输入 | 网络种子 | 训练—总体 | 独立帧—总体 | 训练—独立帧 | 总体梯度在初始特征空间中的能量 |
|---|---:|---:|---:|---:|---:|
| N100 / VAR | 20260901 | −0.8810 | 0.9843 | −0.8807 | 12.55% |
| N100 / VAR | 20260902 | −0.9799 | 0.9965 | −0.9848 | 35.32% |
| N100 / VAR | 20260903 | −0.8425 | 0.9870 | −0.8325 | 31.14% |
| N800 / VAR | 20260901 | 0.9664 | 0.9410 | 0.9332 | 10.97% |
| N800 / VAR | 20260902 | 0.8851 | 0.9440 | 0.9439 | 11.84% |
| N800 / VAR | 20260903 | 0.9119 | 0.9366 | 0.8452 | 10.76% |

N100 / VAR 的三个种子，无论普通梯度下降还是第一步 Adam，训练更新对原始独立帧和总体目标的一阶方向均为上升。256 probes 和另一种归一化没有扭转这个结论。它支持“当前统计目标在这个初始化附近仍有方向冲突”，而不是仅仅训练更新太慢。

N800 / VAR 的三个种子，两种更新都能在一阶上同时降低训练、独立帧、总体目标。不过种子 20260903 的 Adam 图像更新中，训练—独立帧余弦为 0.4782，低于预设的 0.5；不能事后放宽门槛将其写成全部通过。

固定噪声输入没有形成跨种子的稳定改善。512 probes 的初始特征空间仅保留 N100 总体梯度能量的约 0.157%–0.199%、N800 的约 0.125%–0.270%。这只是零 readout 时的结果，不能推广为固定噪声 DIP 没有训练价值。

## 门槛与解读

保守初筛同时要求参数梯度、普通 GD 的图像更新、初始 Adam 的图像更新中三组余弦均 ≥0.5，并要求训练方向对三种原始目标均有一阶下降。N800 / VAR 的 12 个相关记录中 10 个通过，其余输入/数据组合没有通过；这不是重建质量验收。

N800 / VAR 的输出不是单纯被限制到低频：以 DCT 左上 16×16 为粗频带，其投影后的总体梯度有约 61%–75% 能量在粗频带外。但这个百分比不能转换成光学分辨率，也不能证明产生的新细节真实。总保留能量只有约 11%，同样不可忽略。

另外，anchor 来自训练帧。N100 的方向冲突可能同时涉及有限帧协方差误差、anchor 与训练统计的依赖以及目标模型；当前检查没有把这些因素分别识别出来，不能独断归因于一个因素，也不能据此建议真实采集必须增加到 800 帧。

## 验证与下一步

新增测试覆盖零 readout 的链式法则、前层零梯度、JJᵀ 半正定、正交投影幂等及其与实际更新的区别、单位质量图像切向量与 autograd 一致、随机种子复现且不污染调用方 RNG、非有限输入与秩零保护。新增 5 项测试及相关联合测试共 47 项通过。

下一项若继续检查卷积先验，应先排除“仅看零 readout”这一限制：在相同初始重建上检查可激活特征层的完整 Jacobian，而不是直接修改生产网络或宣称 N100 已通过。可使用随机非零 readout，并减去冻结的初始输出保持初始残差为零；该构造只依赖初始化，不使用真值，仍须独立验证其梯度实现。

目前没有启动新的 200 步网络实验。后续即使方向检查通过，仍需将实际帧训练与总体 oracle 诊断明确分开，在相同 200 步预算内报告 best/final 的固定中心 FTC、伪纹理、峰值和真值保真度；独立探针 loss 下降不能替代这些验收。正式 no_mean 继续保持不变。
