# 精确总体 Cs 横向曲率对照

## 已确认的反证：均值误差不能自动筛掉当前伪纹理

重新使用精确有限源照明均值，对四个已完成的精确 Cs 输出做了纯前向检查。没有均值反传，也没有把事后拟合的光度系数用于图像。

| B=2 候选 | 总体均值相对 L2 | N100 独立帧均值相对 L2 | N800 独立帧均值相对 L2 | 图像真值相对 L2 | 环带梯度余弦 |
|---|---:|---:|---:|---:|---:|
| 每步 1 个 probe | 0.045423 | 0.062759 | 0.047851 | 0.271471 | 0.390190 |
| 每步 32 个 probe | 0.035593 | 0.056598 | 0.038581 | 0.295271 | 0.279124 |

更充分拟合的 32-probe 候选在协方差与均值预测上都更好，但图像结构保真度更差、峰值更高。因此，对于这两个固定候选，简单对这两种总体预测误差作非负加权，不会选出更干净的单探针结果。这不是联合优化必然失败的证明，只是否定了“现有毛刺必然被均值误差排除”的推测。

N100/N800 表中的候选图像均是同一批 N100 初始化的重建；这里只改变评价所用独立帧，不代表在 N800 上重新训练。总体均值使用两组数据各自固定系统照明尺度，单位质量图像误差不变。

证据：`outputs/linear_float_oracle_50um/exact_population_fullbatch/mean_forward_audit.json`。历史量化、逐帧最大值归一化数据不在本结论适用范围内。

## 本轮实验

沿用用户之前批准的“仅约束横向 log 修正的 Hessian-Schatten-2 曲率”机制，在已经纠正有限样本 oracle 偏差的精确总体 Cs 对照中重新验证。此前历史数据、有限库匹配和其他损失上的曲率结果不能直接替代这一控制实验。

- 固定 50 µm，2D 自由变量，不改网络、Set/gate、PSF、正式 no_mean，也不启用均值反传。
- 同一 N100 RL3 anchor、seed=20260901、B=2、Adam lr=0.01、完整 32 个训练 sensor probes；每 4 个分块后一次 optimizer 更新。
- 比较初始梯度比 r=0.003、0.01、0.03，复用已完成 r=0 对照，不重新跑 E0。
- 正则作用于 tanh 之前的 raw log residual。前 20 步为零；step 20 用完整累计数据梯度和曲率梯度标定一次 lambda，此后固定。它与按每步梯度重新调整权重不同。
- 严格 200 次更新，step 0–199；每 20 次保存重建和原始变量/优化器状态。训练 loss 为更新前值，保存图像与独立 probe loss 为更新后值。
- best 只由 16 个独立 sensor probes 的协方差 loss 选择，不将曲率、GT、FTC 或肉眼效果加入选 checkpoint 的规则；同时报告 final。
- 检查 step 0/19 与 r=0 控制一致；报告实际梯度比，因为固定 lambda 不保证后期梯度比仍等于初值。
- 比较固定中心 FTC、真值 L2、峰值、环带梯度一致性、径向毛刺、相位一致性及相同显示尺度图像。Laplacian 单独升降不构成胜负判据。

二阶混合范数依据：[Lefkimmiatis、Ward、Unser，Hessian Schatten-Norm Regularization for Linear Inverse Problems](https://arxiv.org/abs/1209.3318)。论文在线性逆问题中研究该正则；本轮作用于非线性协方差反演的 log 修正，是适配而非原论文复现，不能继承全局凸性保证。离散实现精确保持 90° 旋转，不声称离散网格任意角度下完全不变。

## 验证与状态

新增 5 项测试验证 warmup/r=0 不改变梯度、组合梯度等价、标定后权重固定、异常梯度失败保护、90° 旋转和线性 ramp。联合物理与梯度测试 38 项通过。

结果目录：`outputs/linear_float_oracle_50um/exact_population_curvature/r003|r01|r03`。

运行状态必须以进程会话或完成的 `summary.json` 为准，不用本文件推断。三组全部完成后运行 `tools/summarize_population_curvature.py`；该脚本会拒绝不满 200 步、来源不一致、warmup 改变或非 holdout 选取的结果。

没有任何结果仅凭这轮理想协方差与已知单层深度被提升为正式方案。若曲率仅使图像变模糊、或不能兼顾细节与保真，则保留原正式 no_mean，继续记录失败发生于横向反演层面。

## 同等拟合程度的优化路径复核

为区分“同样 200 步但全探针拟合更快”与“优化路径不同”，从已完成全探针轨迹中，按最接近单探针 best 的 log holdout loss 选取诊断检查点，不使用 GT 或 FTC。这个中间检查点不是新的主结果，也不改变 best/final 规则。

|---|---|---|---|---|---|
| 0.5 | 199 / 0.00180068 | 79 / 0.00184515 | 0.28275 / 0.29517 | 1.3573 / 1.6056 | 0.37994 / 0.34160 |
| 2 | 199 / 0.00100872 | 99 / 0.00099821 | 0.27147 / 0.29215 | 1.4395 / 1.9170 | 0.39019 / 0.31501 |

B=2 匹配对的 holdout loss 只差 1.04%，FTC 同为 6.86014 µm，但结构保真度和峰值仍不同。这表明拟合速度差异不是目前伪纹理差异的充分解释；在当前有限 sketch、同一 Adam 学习率和有界残差下，优化路径也产生明显影响。这里只匹配标量物理 loss，不宣称残差向量完全相同、全局唯一性失败，或单探针对任意数据必然更好。

复核函数：`tools.summarize_population_curvature.loss_matched_controls`。三组完成后的汇总会自动包含这些比较。



## 200 步训练最终结果：不采用本轮曲率方案

三组均完成 step 0–199，三个进程正常退出；best 全为 step 199，等同 final。step 0/19 图像与已完成 r=0 控制逐元素完全一致；固定权重、完整步数和仅用独立 probe loss 选 best 的检查全部通过。三组各用时约 1460–1466 秒，峰值显存均为 24.89 GiB。38 项联合测试通过。

| 精确 Cs 固定层诊断 | FTC µm ↓ | 真值单位质量 L2 ↓ | 峰值/真值峰值 | 环带梯度余弦 ↑ |
|---|---:|---:|---:|---:|
| RL3 anchor | 7.317 | 0.32103 | 1.649 | 0.35246 |
| 全 32 探针，r=0 | 6.311 | 0.29527 | 2.337 | 0.27912 |
| 全 32 探针，r=0.003 | 6.403 | 0.29222 | 2.236 | 0.27491 |
| 全 32 探针，r=0.01 | 6.494 | 0.28805 | 2.232 | 0.27167 |
| 全 32 探针，r=0.03 | 6.677 | 0.28542 | 2.210 | 0.27516 |
| 每步 1 探针的先前参考 | 6.860 | 0.27147 | 1.439 | 0.39019 |

最强组相对全探针无正则：全图 L2 改善 3.34%、峰值降低 5.44%，但 FTC 回退 5.80%、局部梯度一致性降低，径向毛刺指标还升高 3.32%。相同显示尺度的图像仍存在额外亮纹和局部尖峰，未获得干净而可信的细线增益。不能把少数指标小幅改善称为净质量胜利。

固定 lambda 并不等于固定梯度比。三组最后一步的实际比例分别达到 0.1162、0.3707、0.9536；最大组已接近数据项梯度范数，不能把本轮失败归因于曲率始终只有 3% 而过弱。该比值在 raw log residual 空间测量，不等于 Adam 预条件后的实际更新比例。

因此，停止追加同类曲率权重训练，不将这三组提升为正式结果。正式 no_mean、Set/gate、PSF 和均值不反传设置保持原状。这个判断仅针对当前有界 log 参数化、总体 Cs 目标、已测权重和 200 步协议，不是关于所有二阶正则或所有协方差重建的否定定理。

这些数字来自线性仿真的已知 50 µm oracle；不能与历史归一化原始帧的正式 E0 当作同条件数据，也不能据此宣称未知深度定位或深度分辨率得到提高。评价像素标尺沿用既有比较协议；绝对光学标尺仍应与生成和成像采样统一核验。

证据：
- `outputs/linear_float_oracle_50um/exact_population_curvature/comparison.json`
- 同目录 `upper_left_comparison.png`
- 三组各自 `summary.json` 及 `reconstruction_best/final.npy`

新的 128 探针独立帧前向复核状态另记；它不改变本轮因图像质量未通过而不采用的决定。



## 独立 128 探针复核最终结果

N100 与 N800 两项只读前向复核均正常完成；所有五个候选在复核前已冻结为 200 步训练选出的 best。新 probe seed=20261030，原训练/选 best 的 probe seeds=20261010/20261011。没有重新优化任何候选或拟合方差尺度。

| 候选 | 新探针总体目标 loss | N100 独立帧 loss | N800 独立帧 loss |
|---|---:|---:|---:|
| 真值 | 0 | 0.86528969 | 0.42728347 |
| 单探针 B=2 参考 | 0.00099244 | 0.86539149 | 0.42783457 |
| 全探针 r=0 | 0.00041250 | 0.86530650 | 0.42748958 |
| r=0.003 | 0.00041975 | 0.86530697 | 0.42749250 |
| r=0.01 | 0.00044350 | 0.86530757 | 0.42750305 |
| r=0.03 | 0.00052548 | 0.86531210 | 0.42754126 |

不同列的损失分母分别使用相应目标向量能量，不能把总体列与有限帧列直接相减解释成物体误差。相同候选的总体目标 loss 在两套数据系统尺度归一化下完全一致，复核了尺度齐次性。

相对 r=0，用同一组 probe 做配对 bootstrap（4000 次、seed=20261031），N100 三组 holdout loss 差的 95% probe-only 区间均跨过零。N800 三组区间均为正，表示预测略差而非更好；最强组的差值为 +5.17e-5，区间约 [2.99e-5, 7.17e-5]。这些区间只反映新 probe 抽样，不包括有限帧的不确定性或场景泛化；效应也很小，不能夸大为大幅退化。

新探针总体目标仍偏好图像保真度较差的全探针候选，说明先前观察不是仅在原 16 个验证 probe 上出现。它仍不能证明对完整协方差的严格非唯一性，因为未计算所有方向，也没有证明达到全局最优。

三组训练及两组复核全部完成，无后台待完成作业。最终结论保持：这三个曲率强度均没有同时带来可信的细节提升与伪影抑制，不进入未知深度、多层或真实数据部署，不追加同类权重训练。正式 no_mean 保留。

证据：同一结果目录的 `independent_n100.json`、`independent_n800.json`，内含全部逐 probe 损失，允许独立复算上述区间。
