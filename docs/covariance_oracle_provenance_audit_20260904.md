# 固定 50 µm 协方差上限：统计来源复核

## 必须更正的结论

此前 5.4–5.6 µm 的实验数字可复现，但不能继续表述为“只知道总体真实 Cs、未知逐帧散斑时可达到的横向分辨率”。这些对照知道的是**有限散斑集合的完整样本协方差**；目标统计和模型统计在各自训练/验证集合内共享这个协方差。它比只知道系统总体 Cs 多了有限集合的随机相关信息。

本轮六组均完成 200 次更新（step 0–199）。没有修改正式 no_mean 网络、Set、gate、PSF 或目标深度推断。已知 50 µm 只用于二维诊断。

## 控制条件

- 同一线性浮点 N=100 数据集的 RL3 anchor；不是历史 uint8 数据，也不是此前 N=800 的新 anchor。
- g 单位质量，bounded-log B=0.5，学习率 0.01，32 个训练/16 个独立验证 sensor 探针，sigma=4。
- 每步完整计算 `H[g Cs(g Hᵀq)]`，不做左侧小矩阵投影，不拟合任何场景方差尺度。
- 系统尺度只使用生成端预先固定的全局值，不做逐帧最大值归一化。
- 有限集合训练 seed=20261012，验证 seed=20261013；独立目标组另用 20261022/20261023。传感器探针 seed 为 20261010/20261011。
- “独立验证”不表示完全盲的实验：matched 组的验证目标和模型仍共用验证集合的样本 Cs。所有 oracle 目标由真值生成；真值图像误差和 FTC 不参与 checkpoint 选择。
- 表中的 128/1024/8192 是**建模散斑集合大小，不是采集帧数**。

独立集合组即使输入真正 g，其验证 relative-MSE 也为 0.4701；anchor 为 0.4518，best 为 0.4380。这是模型样本 Cs 与目标样本 Cs 的失配，不是网络容量问题。它不等价于“采集 1024 帧必定失败”，因为这里两侧均是有限集合，采样分布和误差来源不同。

## 为什么共享有限集合可能提供额外信息

令 `A_g(C)=H D_g C D_g Hᵀq`，样本协方差 `Ĉ=C+ΔC` 且 `E[ΔC]=0`。对于**未归一化平方误差**，共享样本协方差时：

`E ||A_g(Ĉ)−A_truth(Ĉ)||²`

`= ||A_g(C)−A_truth(C)||² + E ||A_g(ΔC)−A_truth(ΔC)||²`。

第二项是依赖真值的额外约束。不能把它默认为总体 covariance 数据项的无偏替代。实际训练使用随机目标能量作为分母的逐探针 relative-MSE，上式不能原封不动套用到那个随机比值；这里只解释额外约束的来源。

新增两个小测试给出直接反例：一个探测器对两个体素求和，总体 Cs=I 时 `(1,0)` 与 `(0,1)` 具有完全相同的输出方差；如果已知某有限样本集合两位置的经验方差不同，共享该样本 Cs 的 oracle 就能区分这两个物体。对独立标准高斯样本，额外平方差的期望为 `4/(K−1)`，数值检查通过。

这说明机制**可以**发生；本次大小扫描与它一致，但尚未定量分离当前光学系统的有限源边界效应、总体非平稳性、随机协方差项和优化条件。因此不声称已经证明全部改善来自随机项。

## 理论边界与后续动作

Idier 等讨论总体二阶统计在特定成像条件下的可辨识性，不保证有限探针、有限步数和有限帧重建的稳定性：[2018 原文](https://pagesperso.ls2n.fr/~idier-j/pub/pubC/Idier18C.pdf)。2023 年方差分析进一步明确：散斑相关长度与观测 PSF 的匹配条件很重要，频率敏感性不等于可唯一恢复：[原文](https://arxiv.org/html/2311.13897v1)。本系统的相位相关 LFM 算子不能不经验证直接套用平移不变显微镜的二倍分辨率结论。

解析平稳 jinc² 是确定性理想化 Cs，**不是有限源生成器的精确总体 Cs**；此前有限源二/四阶矩审计已经发现边缘非平稳性。也不能把本轮失败解释成总体协方差本身毫无价值。

## 探针带宽六组：已完成，不只是计划

随后六组也全部完成 200 步，固定解析平稳 Cs 与理论目标，不改变网络或 PSF；新增 sigma=0/0.5/1/2（B=0.5），并以 B=2 的 sigma=0/4 作容量对照。sigma=0 是去 DC、单位范数的未平滑 Rademacher 探针，仍不是对所有 sensor covariance 方向的穷举。每个组保留 32 个训练和 16 个独立验证探针。未用 FTC 或图像真值误差选 checkpoint；所有 best 均为 step 199。

## 回到有限帧：前向与梯度核查（无新增训练）

用第三组 seed=20260983 的 64 个未平滑 sensor 探针，在已有独立 train/holdout 帧上评估候选。原 N=100 和后续 N=800 数据有相同目标；N100 导出的候选只做前向评估，不在 N800 上重新训练。使用各数据集固定系统尺度，不拟合场景增益。

| 数据 | 实测 train 梯度与理想统计梯度余弦 | 实测 holdout 与理想余弦 | train/holdout 梯度余弦 |
|---|---:|---:|---:|
| 100 帧 | −0.1530 | 0.3850 | 0.0087 |
| 800 帧 | 0.2623 | 0.5373 | 0.2087 |

这里的梯度是在每组**自身 anchor 初始化处**、64 探针平均损失对 bounded-log 残差的梯度，已经包含单位质量归一化。它不是每一步 Adam 更新的测量，也不能直接外推成所有数据集的固定阈值。所谓理想梯度来自同一解析平稳 Cs 的理论目标；偏差包含有限帧采样误差与有限源总体 Cs 失配，不能全归因于某一种噪声。

100 帧还有直接的错误排序：训练 relative-MSE 对 anchor 为 0.851225，对真正目标反而为 0.855429，对改善后的 sigma=0/B=2 为 0.855551。验证帧则给出相反趋势：anchor 0.865360，真正目标 0.861087，候选 0.860932。这说明同一物体的两个帧集合不能稳定提供同一优化方向。

800 帧对候选的排序较合理：原 N100 anchor 的验证 loss 0.442117，sigma=0/B=2 为 0.424867，真正目标为 0.424205。但局部梯度一致性仍弱；“能给几个固定候选大致排序”不足以证明足以驱动高维像素优化。

这些 holdout 是已有诊断数据，被重复用于研究核查，不是全新、一次性的最终测试集。不同 N 使用不同数据集和 anchor，不能将表中变化完全归因于 N。

## 本轮决策

- 不再用共享有限样本 Cs 的 5.4–5.6 µm 数字支持真实数据上线。
- 保留确定性总体近似下 modest 的横向改善证据，但不把它与未知深度重建混同。
- 不追加使用同一原始 relative-MSE 的有限帧网络训练或 gate 调参；首先分离总体 Cs 失配、有限帧统计误差与目标加权的影响。
- 后续候选统计目标必须先在固定形状处验证独立帧的排序/梯度可重复性，再启动 200 步优化。不能仅以增加正则、压低 FTC 或减少训练 loss 代替这项检查。
- 这些证据不说明所有 covariance 方法无效，也不证明原始 no_mean 无问题；只决定当前路线还不具备替代正式基线的依据。

在未知散斑、独立采集帧下同时通过分辨率和结构保真度验收之前，正式结果仍是 no_mean。不能把已知深度二维 oracle 当作轴向分辨率改善。
