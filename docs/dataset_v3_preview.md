## CPU 启动与 GPU 限制

从项目根目录使用含 numpy、h5py、matplotlib、torch 的现有环境运行：

```bash
CUDA_VISIBLE_DEVICES='' PYTHONDONTWRITEBYTECODE=1 OPENBLAS_NUM_THREADS=1 \
  OMP_NUM_THREADS=2 MKL_NUM_THREADS=2 \
  /workspace/xyx/.conda/envs/speckle_net/bin/python -m tools.run_dataset_v3_preview
```

根目录自动命名为 `data/speckle_dataset_v3_<YYYYMMDD>_runNN`，实际启动当天北京时间，
同日递增、不覆盖。入口先只读审计历史源，然后运行新旧 MATLAB 几何测试、生成
三个真值与预览、运行完整 Python unittest、再次核对源保护、输出中文报告和图库。
MATLAB 使用 `-singleCompThread -softwareopengl`；子进程 CUDA 可见设备强制为空。

**本次样本生成流程后续仅允许物理 0 号 A40。** 当前 CPU 预览不占卡，批准后正式
仿真也不能沿用旧的 1:6/全部卡默认值。必须确认物理 0 型号为 A40，检查显存、
利用率和计算进程，忙则等待、不共用、不转去其他卡。以其 UUID 绑定
`CUDA_VISIBLE_DEVICES`，MATLAB 中仅逻辑设备 1 可见。限制同时写入每个对象配置、
运行合同及待批准文件。
