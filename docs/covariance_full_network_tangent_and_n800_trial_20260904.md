# 完整卷积梯度检查与 N800 轨迹对照

## 当前结论与状态

完整网络梯度检查、五组严格 200 步重建和独立 128 探针复核均已完成。**五组没有同时改善分辨率、保真度和独立统计一致性；不接入正式 no_mean，也不继续扩大这一组设置的网络训练。**

首步步幅匹配成功消除了原 CNN 的巨大突跳，但 best 仍没有 FTC 提升，final 的独立误差、峰值和结构误差反而升高。因此不能只用“默认学习率太大”解释剩余失败，也不能把低 FTC 当成真实分辨率收益。该结论仅限本轮固定深度、N800、具体目标/网络/优化设置，不是否定所有协方差或卷积先验方法。

当前证据排除了一个具体解释：N100 的初始方向冲突不只是零 readout 导致前层暂时不能更新。激活全部卷积层后，该冲突仍然存在。N800 的 VAR 引导网络有更一致的方向，但并非所有种子都通过完整初始门槛，因此新增的训练只能称为轨迹诊断，不能称为已通过验收的方案。

随后首步回放发现原网络学习率有严重步幅混杂，追加了一个训练数据驱动的步幅匹配对照。原四组不中途改参数、均运行满 200 步。

## 完整梯度的实现及验证

沿用独立二维诊断网络，不改生产三分支网络：

- SharedFrameEncoder 和二维对应 decoder，通道 16/32/64，reflect context 40。
- 最后层随机非零初始化；残差定义为网络当前输出减去冻结的初始化输出。初始残差仍为零，初始重建仍为同一 VAR anchor。
- 冻结输出是保存的常量，不是每次重算的 stopgrad 当前输出；训练 checkpoint 保存该常量和固定输入。
- 使用有限网络的 VJP/JVP 计算参数梯度、普通 GD 输出方向、初始 Adam 输出方向，以及它们对原始训练/独立帧/总体目标的一阶下降性质。
- 模型有 238,913 个参数。训练梯度能量中，readout 只占约 0.066%–1.258%，确实已激活前层，而非重复上一轮的 16 通道低秩检查。
- 显式小 Jacobian 与 VJP/JVP 等价；零 readout 时退化到已有特征核；参数和随机状态不被诊断修改。
- 实际 48 项相关记录的最大 VJP/JVP 对偶相对误差约 2.11e−7。CPU 用时 119.24 秒。
- 256/512 probes 是嵌套前缀，两种 loss 使用相同观测帧，不能把 48 项当作独立数据重复。

完整结果：`outputs/linear_float_oracle_50um/convolutional_tangent/initial_full_network.json`。

依据是有限网络的链式法则。[DIP](https://arxiv.org/abs/1711.10925) 说明卷积结构值得测试，但不是本任务的保证；[NTK](https://arxiv.org/abs/1806.07572) 的无限宽、固定核收敛结论没有套用到此处。

进一步核对发现，现有 N100 的散斑种子为 20260920，N800 为 20260940，且使用各自的 anchor 和固定系统归一化。**N100 不是 N800 的前缀**，因此不能把这两组方向差异全部归因于帧数。后续若做帧数因果实验，必须使用同一序列的嵌套子集，并保持同一系统标定。当前五组内部共用 N800，不受这个跨数据集混杂影响。

N800 的 800 张训练帧和 800 张独立帧逐帧 SHA256 均唯一，两组无完全相同帧。生成端使用持续推进的同一随机数流的不同区段，没有每批重置种子；系统归一化来自另外 2048 个光场实现。这里只验证仿真数据未意外重复，不是证明真实相机帧时序独立，也没有产生全新测试集。来源与校验和记录在同一实验目录的 data_integrity.json。

## 为什么仍做有限的 N800 轨迹对照

初始门槛是工程预检，不是 200 步成功的必要条件。当前 N800 的三个种子都有共同下降方向，且实际 Adam 图像方向比原像素自由变量更一致，足以支持一个有对照的有限轨迹实验，但不足以赋予生产资格。

保留所有种子，尤其保留未通过完整预检的 20260902，不只跑较好种子。当前 N100 没有据此扩展同类长训练。

- 像素首步图像 L2 变化量：4.81067414e−5。
- 原 CNN 首步图像变化量：2.86282682e−3，即约 59.51 倍。
- 初次 CPU 回放有 1.65e−3 的 raw 初值后端差异，该标定不用于启动训练。

## 解释、图像检查与后续边界

1. 低 FTC 不等于准确分辨率。像素 final 的 FTC 下降约 19.5%，但全图 L2 约翻倍，环带真值梯度余弦从 0.376 降至 0.189。统一强度范围图中出现密集亮点、断裂和弯曲条纹，直接对应用户担心的“不干净”。该结果明确淘汰。
2. 卷积参数化抑制了像素组的严重伪纹理，但没有在 best 中得到更细且准确的细节。不能把“比失败像素组好”替代为“优于原始 VAR”。
3. 步幅匹配控制了一个真实混杂：首步突跳来自极大的图像更新。但完成 200 步后仍未获净收益，不支持继续仅靠更小学习率或多跑种子挽救当前设置。
4. 训练/独立探针目标差异表明泛化问题仍在，但本轮不能进一步分离固定探针、有限帧、anchor 数据依赖与优化偏置各自的因果贡献。旧刷新探针实验使用平稳近似 Cs、不同带宽和 B，并非精确有限源 Cs 的同条件刷新对照；不能用它证明当前模型刷新必然无效，也不能由此直接启动更多长训练。
5. 本轮停止追加参数组，保留正式 no_mean、Set/gate/PSF 和均值反传策略不变。后续新方法先要求在准确性与统计误差排序上有明确可检验依据，而不是只追更低 FTC。未获得相应授权时，不增加均值反传或场景自由标度。

训练循环约 24.3–24.7 分钟/组，不含 PSF/模型初始化；峰值分配显存约 24.9–25.1 GiB。五组使用空闲 GPU 并行，后续前向复核结束后全部 GPU 已释放。新增配对探针统计测试与已有物理/梯度/状态恢复联合测试共 53 项通过。

本数据不是原始经过逐帧归一化的仿真，不能把这里的绝对 FTC 与原始 E0 直接混比。固定真实 50 µm 和单位质量属于诊断先验，不能宣称完成未知深度、100 帧或任意真实三维样品重建。整个提高质量与深度分辨率的目标尚未完成。
