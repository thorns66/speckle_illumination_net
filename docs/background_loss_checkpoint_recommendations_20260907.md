# 背景来源、均值与方差结合、checkpoint 选择：诊断与建议

本次新增诊断使用首轮第 160 步冻结模型，没有更新网络参数。11 组空输入路径实验、两张图各 8 档输入缩放、6 组重建体梯度检查，以及 3 组十帧均值亮度投影均已完成。所有新结果在 `outputs/background_diagnosis_20260907`，原验证结果保持原样。

## 1. 背景为什么出现

确认输入、归一化后的输入、anchor 都严格为零；零输入的重建与此前保存结果完全一致。问题发生在残差网络内部和最终融合处。

当前输出公式在 anchor 为零时，严格退化成：

`output = max(decoder_residual, 0)`

也就是说，只要解码器产生正残差，就能凭空增加非零输出。输入为零并不保证神经网络中间特征为零：Conv 的 bias、GroupNorm 的可训练偏置、卷积边界、Set 分支的深度坐标以及 `sqrt(feature_variance + 1e-8)` 的非零下限都可能产生确定性特征。

实测结果如下。这里的关闭和置零只发生在诊断进程中的模型副本，不是可直接应用到已训练模型的修复方法。

| 冻结模型诊断 | 空输入输出总量 |
|---|---:|
| 原模型 | 5844.98 |
| 关闭 Set 分支 | 6728.82 |
| Set 的深度坐标置零 | 5700.15 |
| 关闭三个输入分支，保留融合和解码器 | 9338.52 |
| 给解码器直接送全零特征 | 26044.96 |
| 只删除最后一层 bias | 5666.20 |
| 关闭残差修正，只保留 anchor | 0 |

因此不能归罪于 Set 一条分支，也不能靠删除最终 bias 解决。最终 bias 为 0.000513，删除它只降低约 3.1% 的空输入总量。

原模型空输入时约 51.8% 体素为正，输出并非均匀常数；其质量主要落在 60–80 µm。编码器的 RMS 归一化没有把精确的零除成非零，但在非零输入下会消除整体亮度变化，而解码器的加性残差没有乘回输入亮度。

### 输入变暗时，输出有没有跟着变暗

把所有强度型网络输入共同乘 c，包括开方一次的 Taylor、Mean 初始重建和去均值帧；固定原来解析 beta0，直接检查网络的尺度响应。它是受控的网络接口诊断，没有重新运行 RL，也不是加相机噪声实验。

| 输入亮度倍数 c | 60 µm 点图输出总量 | 60 µm 线图输出总量 |
|---:|---:|---:|
| 0 | 5844.98 | 5844.98 |
| 0.01 | 285.50 | 320.51 |
| 0.1 | 139.97 | 370.93 |
| 0.5 | 140.35 | 373.41 |
| 1 | 140.76 | 376.83 |
| 2 | 141.54 | 383.76 |

输入变成十分之一时，输出仍然几乎保持原亮度。相比仅讨论空输入，这更直接暴露了残差输出没有正确响应输入强度的问题。两张正常输入的原始输出也已逐体素复现，误差为零。

不能由此断言所有正常样本都包含与空输入相同的背景。零输入和正常输入经过非线性网络时处在不同状态。试着从正常重建中直接减去空输入输出并截断，会去掉上述两张图约 54.3%、56.3% 的总量；这些被减掉的量不能全部认作背景。因此不建议把零输入输出当作固定背景模板相减。

### 建议的修复

1. **小范围过渡方案：整体亮度投影。** 用前十帧均值给最终重建拟合一个全局非负系数。空输入时该系数为零；非空输入只改变亮度，不改变相对结构。它不能消除非空图中的局部假结构。下节已给出实测。
2. **正式结构修复：让残差随输入亮度缩放。** 从前十帧均值计算一个标量亮度 s，相对于训练集预先固定的参考亮度。各输入先除以同一个 s，网络在参考尺度工作，最终整个输出再乘回 s。零输入单独返回零。只有除法分母可设数值下限，外侧 s 不能被抬成非零值。这样可把 `f(c x)=c f(x)` 作为明确约束，而不是期待网络从有限数据里自行学会。
3. **需要重新训练或至少独立微调。** 不能直接给原 checkpoint 的残差乘一个很小的 RMS 就宣布修好；原有残差的数值单位会改变。原始 Taylor 平方体若用于特征，应按 s² 缩放，开方后的幅度体按 s 缩放。
4. **加入零输入和暗输入验证。** 无噪声条件下要求精确零输入输出为零；对 0.1、0.5、1、2 倍亮度检查完整数据管线的缩放响应。训练亮度增强时，均值目标乘 c，方差目标乘 c²，不能二者都乘 c。相机噪声加入后需另行处理噪声底。

不首选把输出强制写成 `anchor * exp(residual)`：它会限制 anchor 为零或很弱的位置，可能堵住漏检弱目标的恢复路径。公共亮度尺度配合加性残差仍允许在有数据依据的位置补结构。

## 2. “把跨层相关项纳入预测”到底是什么意思

令 A 是浅层目标对同一个传感器像素的贡献，B 是深层目标的贡献。相机看到的是 A+B。其方差为：

`Var(A+B) = Var(A) + Var(B) + 2 Cov(A,B)`

如果 A 和 B 经常同时变亮、同时变暗，最后一项就是正数。例如各自方差为 1、协方差为 0.5，总方差就是 3，直接相加却只得到 2。

这里说的是强度随照明共同起伏，不是在说两个荧光目标发生相干干涉。当前数据使用同一复散斑场向不同深度传播，不能默认各层照明独立。

本轮轴向点对的三个重复中，“总方差减去各层真实方差之和”占总方差的 36.5%、34.9%、33.3%。这是该轴向测试场景的证据，不是所有样本都适用的固定修正系数。

当前代码的 `H2(g²)` 实际还忽略了同层不同位置之间的相关性。更准确的表述应为：**补上同层和跨层的散斑协方差**，不能只给当前方差图乘 1.35 或 16。

用密度 rho、照明 e、照明均值 mu_e、协方差 C_e 表示，无噪声时统一的物理关系为：

`mu_pred = H(rho * mu_e)`

`V_pred = diag(H diag(rho) C_e diag(rho) H^T)`

H 是现有保留相位位置的 LFM 算子，不能替换成普通二维卷积。若仍让网络输出 `g = rho * sigma_e`，均值前向应使用 `H(g * mu_e / sigma_e)`，方差前向应使用相应的标准化相关矩阵；不能把密度、均值亮度体、方差幅度体混称成同一个量。

文献中的 RIM 方差表达式也包含密度两位置之间的照明协方差。参见 [Labouesse 等的原文公式 5](https://arxiv.org/html/2311.13897v1)。本文献是对公式的支持，不能据此直接声称本项目能达到其中的分辨率上限。

### 具体实现路线

先做参考前向，暂不改变训练：准备一组独立的完整三维散斑 e_k，每个样本和候选使用同一标定库，计算 `y_k=H(rho*e_k)`，然后直接计算这些 y_k 的均值和 N−1 方差。它自动包含同层和跨层相关项，不需要建立巨大的稠密协方差矩阵，也不需要知道测试采集每一帧的真实散斑。

标定库必须独立于评分用的照明，且保留同一散斑在所有深度上的联合关系。已有 1024 帧标定只保存了逐体素 sum 和 sum_squares，**这些文件不能恢复协方差**；需要按保存的种子重新生成三维照明，或使用独立新标定库保留中心化三维样本。

先在小规模点、线、多层目标上检查 64、128、256、512/1024 个标定样本的收敛、独立照明误差以及候选排序是否稳定，再考虑压缩、低秩或随机探针加速。不能未经验证把一个二维 Cs 核复制十层当作完整三维模型，也不能认定任意小数量模式足够。

这一更完整的前向仍是统计模型；有限标定和有限 90 帧目标会有抽样误差。即使前向修正，也不保证每个独立有限采样目标都一定给 GT 最低分。

## 3. 为什么以前加均值 loss 会把深度拉偏，如何结合

上次“重新启用均值项”的建议太直接，应先解决两项对亮度的要求不同，以及梯度强度不同的问题。Mean-RL 深度分辨率差不等于传感器均值没有用；将 `H(g)` 与传感器均值比较，也不是把三维输出硬拉到 Mean-RL 初始重建。

对 P08、P09、P10 的 subset 01 网络输出，采用第一套新照明后 90 帧目标，计算得到：

| 对象 | mean 梯度范数 / variance 梯度范数 | 两项梯度余弦 |
|---|---:|---:|
| P08 | 18.16 | 0.176 |
| P09 | 85.63 | 0.162 |
| P10 | 18.24 | 0.127 |

这是**对输出三维体的梯度**，不是网络参数梯度，也不是对之前失败训练的重跑。证据说明等权相加很容易被均值项主导；当前三个输出上的梯度也不是全部相反，不能只归结成“梯度方向冲突”。

实际加权 TV 梯度在这些输出上只有方差梯度的约 2.3e-8–1.3e-7，支持“本轮 TV 基本不起约束作用”。单凭 TV 的 loss 数值很小本来还不足以下这个判断。

### 已实测的过渡方案：均值只管整体亮度

令 g0 是冻结网络输出，p=H(g0)，mu10 是同十帧传感器均值。计算一个全局非负最小二乘系数：

`a = max(<p, mu10> / <p, p>, 0)`，最终输出 `g=a*g0`。

需要数值保护；mu10 全零时直接令 a=0。没有逐层系数，没有用 GT 或九十帧目标拟合 a。九十帧独立目标仅用于下面评分。

| 对象 | 从十帧拟合的 a | mean loss：前 → 后 | 当前 variance loss：前 → 后 |
|---|---:|---:|---:|
| P08 | 0.1087 | 7.965 → 0.0855 | 0.196 → 2.469 |
| P09 | 0.0791 | 10.496 → 0.2644 | 0.104 → 0.483 |
| P10 | 0.0773 | 10.821 → 0.0692 | 0.193 → 2.422 |

三个输出的归一化三维结构最大变化不超过 2.91e-11；峰位、相对阈值检测、归一化深度分布在数学上不受正标量乘法影响。空输入输出严格变成零。

因此，**可以利用均值校正亮度而不拉深度，但当前方差模型不能同时得到满意的绝对亮度评分**。这也再次说明问题不只是寻找一个合适的 lambda。这个变体只在独立诊断目录保存，不能用于回头替换本轮正式预测或重新拟合正式候选。

### 下一轮推荐顺序

1. 先保留结构输出，用上述十帧全局亮度约束作为明确的独立基线，验证空/暗输入、弱目标和亮度准确性。它不修复原方差项的错层偏好。
2. 若此时要训练组合模型，明确拆分形状 q 和整体幅度 a：mean 的梯度只允许更新 a，不能进入 q；var 对 q 使用去掉全局幅度自由度后的形状损失。可用固定传感器掩膜上的中心化 log 方差，但需固定 epsilon、检查暗区敏感性，不能当成完整物理 loss 的最终替代。若 a 直接从十帧解析计算，mean 只是解析约束和评分，并非需要反传的训练项。
3. 更完整的三维协方差前向通过标定后，再开放 mean 对结构的梯度。先做方差热身，再将 mean 的加权梯度强度从方差梯度的 10% 缓慢增加到至多 30%。这是下一轮建议的预设范围，不是本轮已经验证的最佳值。
4. 权重应参考同一组共享参数上的梯度范数，采用平滑估计：`lambda_mean = eta * ||grad_var|| / (||grad_mean|| + eps)`，并设上限，防止方差梯度接近零时不稳定。完整统计前向核对不过关时，不能靠这条公式补救物理错误。
5. 若核对后仍有持续负梯度余弦，可评估 PCGrad 一类处理；它只处理优化中的方向冲突，无法补回漏掉的协方差。[PCGrad 原论文](https://arxiv.org/abs/2001.06782)。

不建议直接大幅增加 TV 来处理上述背景：它会压平变化，却未必惩罚近常数的正背景，还可能抹掉细线和弱点。

## 4. checkpoint 必须用验证集选择

训练集用于更新参数，验证集用于选 checkpoint 和调方案，测试集在方案冻结后评一次。[scikit-learn 的数据划分说明](https://scikit-learn.org/stable/modules/cross_validation.html)。

当前主验证对象是 P09、V01、V02。P08/P10 是训练对象，不能加入主验证分数。P07、T01、T02 是原测试对象；既然其结果已经被查看并用于讨论改法，应将它们的后续结果称为固定历史基准。若要声称严格的最终泛化评估，需要新增未参与决策的物体、几何和照明。只换同一物体的十帧子集不能消除对象层面的重复。

本轮 33 组点线诊断也已经影响下一轮设计，应明确作为开发验证/回归检查。训练过程不使用 GT，但如果 checkpoint 选择使用验证 GT，报告应写明“训练无 GT，模型选择使用仿真 GT”。

### 一套可执行的预设规则

**频率与分组：** 每 20 步验证和保存。先在 P09、V01、V02 上计算每个对象十个输入子集的均值，再对三个对象等权平均。十个高度重叠的九十帧补集不视作十次独立重复。

**主分数：** 下式用于下一轮，权重在训练前锁定，不根据测试集反复修改；越低越好。

`S = 0.35 E3D + 0.45 (Dlocal / 10 µm) + 0.20 Bfalse`

- E3D：允许一个整体亮度对齐后的三维 NRMSE，禁止平移对齐或逐层调亮度。它单独回答结构是否相似；原始尺度误差和均值误差必须并列记录。
- Dlocal：固定局部区域内的 Z 分布 W1，除以一层 10 µm。用 GT 仅确定评分区域，在每个局部区域比较完整十层分布，再等权汇总，防止两个位置深度互换却在全图 Z 总量上抵消。区域预先固定，未检测到的目标记漏检，并给最大范围 90 µm 误差，不能删除失败点再算平均。
- Bfalse：目标在 XY 扩展两个重建像素、Z 扩展一层之外的质量比例。必须基于局部三维支持，不能只看整幅图有哪些 Z 层为空；几乎全零输出直接列为漏检，不允许靠这个指标得高分。

当前已保存的 `gt_axial_w1_um` 是全体 Z 质量指标，`gt_support_outside_pm10_mass` 只按全图占据层计算，不能直接改名字冒充上面两个局部指标。下一轮需要补这两个实现。XY-MIP SSIM、点宽度和点对分开率继续展示，但不独自决定赢家。

**候选必须过的检查：** 以下都是下一轮工程验收建议，需要在新训练前锁定。

- 无噪声精确零输入，输出最大值不高于 1e-8；另记录相对固定正常验证参考的总量比例。
- 0.1、0.5、2 倍亮度完整管线试验，相对 `c * 原输出` 的 L2 偏差不超过 10%。这是一项建议容差，尚未验证可达性；增加相机噪声后必须重新规定。
- 诊断单点定位成功率至少 95%，用既定 XY 两像素/Z 一层标准。
- 连续线假断率、断口误连接率均不能比锁定的第 160 步参考恶化超过 5 个百分点；未匹配峰数按真实目标数归一化后，增长不超过 0.05。必须逐几何、逐亮度及逐次采集记录，不靠合并平均掩盖弱目标失败。
- 必须有限、非负，无明显整对象漏检。更窄的假峰不能提高分数。

**选择流程：** 先按 S 排序，在排名靠前的 checkpoint 上逐个运行同一套点线/空暗输入检查，选择第一个通过者。若所有候选都不通过，明确报告没有合格模型，不通过放宽阈值硬选。S 差异小于 1% 时选择更早一步；这个阈值是工程上减少挑选波动的约定，不是统计显著性。

**物理 loss 的位置：** 当前存在偏差的方差 loss 暂时并列展示，不加进主选择分数。协方差前向通过独立标定后，用均值/方差与独立目标的重复波动建立合理误差范围，作为数据一致性检查；不能未经标定拿一个固定 loss 阈值当物理正确证明。

正式评估时单独报告三次照明重复，不将预测先平均。置信区间以独立物体为主要分组单位，照明作为物体内重复；只有三个验证对象时，不应给出过于精确的总体泛化结论。
